# 06 — Engineering Records

This directory contains completed and in-progress engineering records produced specifically for VC-005.

Blank reusable templates belong in CT-001. Completed instances belong here.

## Subdirectories

- `Engineering_Sessions/`
- `Engineering_Decisions/`
- `Evidence_Register/`
- `Scene_Analyses/`
- `Scene_Scorecards/`
- `Transition_Audits/`
- `Certification_Exports/`

## Documentation Rule

Every material engineering decision must be documented when it is made, linked to supporting evidence, and reflected in the appropriate scene analysis or scorecard.

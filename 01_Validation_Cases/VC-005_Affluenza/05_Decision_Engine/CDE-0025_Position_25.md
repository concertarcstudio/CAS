## Lessons for CDE v1.1

1. Add a required candidate evidence manifest covering album or edition, duration, availability, lyrical theme, energy profile, and verified source location.
2. Define whether decimal criterion scores are permitted and specify rounding precision.
3. Add an explicit numeric confidence aid based on input completeness, lead margin, and elimination stability while retaining qualitative human judgment.
4. Separate `automatic recommendation` from `automatic placement`. The former may stop search at High confidence; the latter remains prohibited.
5. Add a standard no-elimination disposition so a valid zero-elimination run is unambiguous.
6. Define stable record placement and index requirements for case-specific CDE outputs.

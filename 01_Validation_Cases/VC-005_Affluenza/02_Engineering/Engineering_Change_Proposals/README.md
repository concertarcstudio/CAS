# Engineering Change Proposals

Engineering Change Proposals (ECPs) document suggested modifications to the authoritative VC-005 engineering baseline.

An ECP separates experimentation from approval. Creating an ECP does not change the baseline. A proposal must be reviewed, challenged, and resolved through an Engineering Decision before implementation.

## Statuses

- **Draft** — Proposal is being developed.
- **Under Review** — Blue Team and Red Team review are active.
- **Approved** — Authorized for baseline implementation.
- **Rejected** — Not adopted.
- **Deferred** — Retained for later evaluation.
- **Closed** — Decision and any approved implementation are complete.

## Required Traceability

Each ECP should reference the related Transition Audits, Engineering Decisions, evidence, baseline revision, and implementation commit when applicable.

# FC-0002 — Transition Function Classification

**Status:** Candidate  
**Source:** VC-005 / ES-0001

## Definition

Every transition should be assigned one primary engineering function that describes its principal contribution to the scene.

## Candidate Functions

- Establish
- Escalate
- Expand
- Reinforce
- Contrast
- Release
- Resolve
- Re-center

## Purpose

Provide a consistent engineering vocabulary for Transition Audits and make scene-level function patterns visible.

## Validation Plan

Apply the classification through the remainder of VC-005. Review the vocabulary for duplication, gaps, and practical value before proposing adoption into CAS-T-203.

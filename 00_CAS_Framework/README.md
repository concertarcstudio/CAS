Status: **v0.1 Foundation complete**

- CAS-T-201 — Scene Analysis
- CAS-T-204 — Engineering Decision
- CAS-T-205 — Evidence Register

Blank rich-format templates remain in the companion document library. GitHub stores their documentation, indexes, change history, and text-based reference materials.

## Reference Qualification

An artifact becomes a reference implementation only after it has been completed, reviewed, and confirmed to follow VA-0001. Pending artifacts document the intended validation chain but do not serve as examples until their status changes.

## Maintenance

Update this index when a reference implementation is added, superseded, or retired. Any change to the validation method itself must proceed through a Framework Contribution (FC).

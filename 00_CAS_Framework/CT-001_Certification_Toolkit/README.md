# CT-001 — Certification Toolkit

**Status:** v0.1 Foundation complete

CT-001 provides the reusable tools used to document, evaluate, and certify CAS engineering work.

## Core Four

1. **CAS-T-201 Scene Analysis** — defines scene purpose, narrative function, track range, risks, and findings.
2. **CAS-T-204 Engineering Decision** — records material decisions, alternatives, evidence, and disposition.
3. **CAS-T-205 Evidence Register** — maintains traceable evidence linked to decisions and certification claims.
4. **CAS-T-206 Scene Scorecard** — records provisional and final scene-level evaluation.

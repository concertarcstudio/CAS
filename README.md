# CAS

**Where Playlists Become Performances.**

CAS (Concert Arc Sequencing) is a documented engineering framework for transforming playlists into intentional, concert-style listening experiences.

## Core Philosophy

> Every decision is intentional. Every decision is documented.

## Repository Purpose

This GitHub repository is the engineering headquarters for CAS. It tracks framework documentation, validation-case records, changelogs, decisions, and release history.

Rich-format source documents, spreadsheets, figures, and final publication files may remain in the companion Google Drive library, with GitHub retaining the engineering record and version history.
